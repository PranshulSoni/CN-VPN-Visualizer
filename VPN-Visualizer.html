      Model boundaries & references
      
    All OSI layers are illustrated; real Internet protocols span layers. Application, presentation and session
        headers are teaching metadata. AES-256-GCM and SHA-256 run locally with Web Crypto. The VPN uses a simplified
        UDP-encapsulated L3 tunnel, not an interoperable IPsec or WireGuard implementation. TCP checksums omit the IP
        pseudo-header. Frames omit preamble, minimum-size padding and inter-frame gaps. NRZ/Manchester/NRZI, bit
        stuffing, VLAN and shared-Ethernet collision experiments illustrate different media, not one Ethernet
        specification. The initial secure key negotiation is a conceptual animation, not an implemented key-exchange
        protocol.
